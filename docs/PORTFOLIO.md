# 作品集说明

## 项目定位

AI Game Workbench 是本地优先的游戏素材工作台。本版本基于 [kazusa000/ai_game_workbench](https://github.com/kazusa000/ai_game_workbench) 二次开发，重点探索素材整理、角色档案与提示词复用，适合展示从个人需求到可运行产品的迭代过程。

## 使用流程

1. 导入已有图片或生成结果，浏览、收藏并标注素材。
2. 创建角色档案，记录人设、外貌锚点和参考图。
3. 选择角色与提示词模板，填写动作、服装或画风等变量，复制提示词到外部生图工具。
4. 将外部生成结果重新导入，并关联回角色档案。
5. 按需要使用原有高清角色、像素角色处理流程或选用 ComfyUI 接入。

## 技术结构

- 前端：React、TypeScript、Vite。
- 后端：Fastify、TypeScript，本地文件与 JSON 索引。
- 共享层：npm workspaces 下的 `packages/core`。
- 验证：Vitest、TypeScript 类型检查、生产构建。
