# AI Game Workbench

**本地优先的 AI 游戏素材与角色提示词工作台。**

## 项目简介

基于开源项目 [ai_game_workbench](https://github.com/kazusa000/ai_game_workbench) 二次开发，围绕游戏角色素材制作，探索角色档案、提示词复用与素材管理。项目通过 AI 辅助编程迭代，重点关注使用流程与素材组织。

## 主要功能

- **角色与提示词**：维护角色设定、参考图及提示词模板，组合后用于外部生图工具。
- **素材管理**：导入、浏览、收藏和导出素材，关联角色、提示词与生成结果。
- **角色素材流程**：保留高清 2D、像素角色、动画后处理与 Godot 导出相关能力。
- **可选工具接入**：提供 ComfyUI 工作流提交界面，以及 Live2D 模型与贴图记录入口。

**技术与实现**：React、Vite、Fastify、TypeScript 与 Node.js。

**使用边界**：图像反推功能生成供外部视觉 AI 使用的分析指令，并非内置识别模型；Live2D 功能不等同于完整模型制作或绑定。生成结果依赖所用模型与服务。部分流程需要外部 API；启动公网隧道会将本地素材服务临时暴露于网络。
